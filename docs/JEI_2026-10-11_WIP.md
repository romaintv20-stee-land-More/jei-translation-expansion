## Translation staging (NOT a release)

- Source-only translations have been staged under translations/staged-published-2026-10-11.
- 16 JSON generations and 4 legacy .lang generations are staged.
- For each locale: first preserve safe, official JEI translations; otherwise reuse only the old project-owned translation when BOTH its key and source English value are identical; finally use the exact latest English source as explicit fallback.
- Removed keys are not emitted. New or meaning-changed keys are NOT inherited from old translations.
- The 26.3 G53 proposal is separately staged in translations/g53-mc26.3-31.10.0.63, with 89 locale files and 614 real English keys.
- English fallbacks for new or changed meanings require human review and language-specific translation before a stable public release.
- Static scripts verify all 20 staged generations and placeholder preservation. Runtime behavior remains untested.
